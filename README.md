# InvenSchool

Sistem Informasi Inventaris Sekolah

## Struktur Proyek

- **Api/** - Backend API (Laravel)
- **Mobile/** - Aplikasi Mobile (Flutter)
- **Arsitektur/** - Dokumentasi arsitektur database
- **ERD/** - Entity Relationship Diagram
- **TechStack/** - Dokumentasi teknologi yang digunakan

## Tech Stack

- **Mobile:** Flutter + Dart
- **Backend:** Laravel + PHP
- **Database:** MySQL
